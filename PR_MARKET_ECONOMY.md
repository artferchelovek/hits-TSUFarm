# Описание Pull Request

## Summary
- **Динамическая экономика и Рынок**: Реализована полноценная система торговли. Теперь товары можно сдавать на Рынок, где они копятся и автоматически продаются каждое утро. Внедрена механика «спроса и предложения»: цены на товары динамически меняются в зависимости от объема продаж.
- **Система прогрессии (Уровни)**: Введена система из 5 уровней города. Новые уровни открывают доступ к продвинутым постройкам и культурам. Для повышения уровня необходимо накопить средства и доставить требуемые ресурсы прямо в Ратушу (Главное здание), что создает четкие игровые цели.
- **Эксплуатационные расходы и Баланс**: Здания теперь требуют ежедневного содержания (maintenance), что заставляет игрока оптимизировать производство. Полностью перебалансированы стартовые цены и бюджет для создания интересного игрового цикла.
- **Улучшение ИИ и навигации**: Исправлены критические баги, из-за которых жители (фермеры и логисты) застревали с полным инвентарем. Внедрена система экстренной очистки инвентаря и многофункциональная разгрузка (склад/рынок/ратуша).

## Changes
- **Core Logic (`src/Store`, `src/engine`)**:
  - `Processor.ts`: Добавлена логика ежедневных продаж и списания налогов на содержание.
  - `GameStore.ts`: Реализован экшен `upgradeLevel`, обновлена логика расчета стоимости построек (фиксированная цена для домов vs цена за площадь для дорог).
  - `CitizenWorker.ts`: Полностью переработана логика поиска складов (`findUnloadTarget`) и внедрен механизм предотвращения тупиков (`stuckCounter`).
  - `Constants.ts`: Добавлен конфиг уровней (`LEVEL_CONFIG`), прайс-лист ресурсов и обновлены параметры всех зданий.
- **UI Components (`src/components/UI`)**:
  - `MarketPanel.tsx`: Новый компонент для отслеживания рыночных котировок и трендов цен.
  - `StatisticPanel.tsx`: Добавлен финансовый отчет (Доход/Расходы/Прибыль).
  - `MainInfo.tsx`: Реализован интерфейс улучшения города с прогресс-барами ресурсов.
  - `BuildingsPanel.tsx`: Добавлена визуальная блокировка (🔒) зданий, недоступных по уровню.
- **Assets & Style**:
  - `src/assets/svg`: Полное обновление графического пака (здания, люди, ландшафт) в едином контрастном стиле.
  - `index.css`: Стандартизация слоев через CSS-переменные (Z-index).

## Notes
- Введена принудительная сериализация данных при отправке в Worker для предотвращения ошибок `DataCloneError` (из-за Immer-прокси).
- Логисты теперь могут одновременно обслуживать одно здание (лимит увеличен до 3 человек), что ускоряет наполнение складов.
- Файлы сохранений (`tsufarm_*.json`) добавлены в `.gitignore`.

## What bugs have these changes
- Исправлен баг «вечного замирания» жителей при переполненных складах.
- Устранена ошибка рассинхронизации рынка, когда проданные товары возвращались в инвентарь после синхронизации с воркером.
- Исправлено некорректное умножение стоимости для зданий с фиксированным размером (Дома, Амбары).
- Исправлены синтаксические ошибки в логике движения, приводившие к падению сборки.
